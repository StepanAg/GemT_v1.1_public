<a id="возможности"></a>
## ✨ Возможности бота

| Категория | Что умеет бот |
| :--- | :--- |
| 👥 **Подписка** | **Автоматическое подключение:** Чтобы начать получать рассылку, пользователю достаточно отправить любое сообщение боту. |
| ⏰ **Расписание** | **Авто-отчеты 2 раза в неделю:**<br>• *Пятница (13:30):* Регуляторный обзор решений ЦБ РФ, Минфина и Казначейства.<br>• *Вторник (14:00):* Дайджест юаневой ликвидности и рынка облигаций.<br>• *Дни и время отправки легко меняются через меню.* |
| ⚡ **Генерация** | **Мгновенный отчет:** Кнопка «Отправить сейчас» сформирует свежую аналитику вне расписания. |
| 💬 **ИИ-Консультант** | **Живой диалог:** Возможность задавать боту произвольные рабочие вопросы и получать развернутые ответы в реальном времени. |
| 🛑 **Управление** | **Отмена и пауза:** Команда `/stop` мгновенно останавливает генерацию отчета или ставит рассылку на паузу. |
| 🧙‍♂️ **Настройка роли** | **Адаптация аналитики:** Бот может выступать в роли сотрудника Казначейства, ALM или ЦБ РФ, опираясь на 17 надежных источников (ЦБ РФ, Мосбиржа, НРД, НКЦ, RusBonds и др.). |
| 🪙 **Лимиты** | **Контроль расходов:** Автоматический контроль дневного лимита запросов к нейросети с наглядным прогресс-баром. |
| 🧹 **Форматирование** | **Чистый текст:** Ответы автоматически очищаются от лишних технических символов для удобного чтения с телефона. |

<a id="быстрый-запуск"></a>
## 🚀 Быстрый запуск

```text

Для запуска бота не требуется писать код. Достаточно выполнить 3 простых шага
(или передать эту инструкцию системному администратору):

1.  Получите ключи доступа (API keys):

      - Токен для бота от Telegram (через бота @BotFather).
      - Ключ API для нейросети от Google Gemini.

2.  Создайте файл конфигурации .env: Создайте в папке с программой текстовый
    файл с именем .env и впишите туда полученные ключи:

    TELEGRAM_BOT_TOKEN=ваш_токен_телеграм
    GEMINI_API_KEY=ваш_ключ_gemini

3.  Запустите бота: Установите необходимые компоненты и запустите главный файл:

    pip install -r requirements.txt
    python bot.py
```

<a id="архетиктура"></a>
## 📁 Архитектура проекта

```text


Программа состоит из нескольких простых модулей, каждый из которых отвечает за
свою задачу:

  - 📄 bot.py — Главный модуль. Отвечает за работу кнопок меню и общение с
    пользователем в Telegram.
  - 🤖 gemini_client.py — Модуль связи с искусственным интеллектом Google Gemini.
  - ⏰ scheduler.py — Планировщик задач. Отправляет отчеты строго по расписанию.
  - 💾 storage.py — Хранилище данных. Запоминает настройки, список подписчиков и
    лимиты.
  - 🔐 .env — Файл с ключами доступа.
  - 📋 requirements.txt — Список необходимых служебных библиотек.
```

<a id="зависимости"></a>
## 📦 Зависимости

```text

Для работы бота используются следующие готовые компоненты:

  - aiogram — библиотека для работы с Telegram Bot API.
  - google-genai — официальный модуль для взаимодействия с нейросетью Google
    Gemini.
  - apscheduler — фоновый планировщик рассылок по времени.
  - python-dotenv — инструмент для безопасного чтения ключей из файла .env.
```

Важные уточнения:
1. ФАЙЛ .env МОЖЕТ НЕ ПОТРЕБОВАВТЬСЯ, В ДАННОЙ РЕПОЗИТОРИИ ЕГО НЕТ, Т.К. API УЖЕ ЗАПОЛНЕН В ОБЛОЧНОЙ ПЛАТФОРМЕ.
2. ЕСЛИ ДАННЫЙ ФАЙЛ ЗАПУСКАЕТСЯ С ЛОКАЦИИ, КОТОРАЯ НЕ ПОДДЕРЖИВАЕТ GEMINI, ТО БОТ С БОЛЬШОЙ ВЕРОЯТНОСТЬЮ БУДЕТ ВЫДАВАТЬ ОШИБКУ, ДЛЯ КОРРЕКТНОЙ РАБОТЫ СОВЕТУЕМ ИСПОЛЬЗОВАТЬ ВИРТУАЛЬНЫЙ СЕРВЕРА, С РАСПОЛОЖЕНИЕМ ПОДХОДЯЩИМ ДЛЯ GEMINI.
