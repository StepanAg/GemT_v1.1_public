<a id="возможности"></a>
## ✨ Возможности бота

| Категория | Что умеет бот |
| :--- | :--- |
| 👥 **Подписка** | **Автоматическое подключение:** При первом сообщении боту пользователь регистрируется в базе рассылки. Доступна кнопка «❌ Отписаться». |
| ⏰ **Расписание** | **Авто-отчеты по расписанию:**<br>• *Пятница (13:30):* Обзор изменений регуляторных требований ЦБ РФ, Минфина и Казначейства («Нормативы»).<br>• *Вторник (14:00):* Дайджест юаневой ликвидности и рынка облигаций («Юань»).<br>• *Дни недели и время легко настраиваются через Telegram-меню.* |
| 🚀 **Генерация** | **Мгновенный отчет:** Кнопки «📌 Нормативы» и «📌 Юань» в разделе «Отправить сейчас» формируют свежий анализ прямо в момент запроса. |
| 💬 **ИИ-Консультант** | **Живой диалог:** Задавайте боту любые рабочие вопросы в свободном формате на базе модели **Gemini 3.6 Flash** с функцией онлайн-поиска (Google Search Tool). |
| 🛑 **Управление** | **Остановка и Пауза:** Команда `/stop` мгновенно отменяет текущую генерацию текста или приостанавливает глобальную рассылку для всех подписчиков. |
| 🧙‍♂️ **Настройка роли** | **Двойная экспертиза:** ИИ выступает одновременно в роли **Методолога ЦБ РФ** и **Руководителя Казначейства/ALM**, с опорой на 17 приоритетных официальных источников (cbr.ru, minfin.gov.ru, moex.com, rusbonds.ru и др.). |
| 🪙 **Лимиты** | **Контроль расходов:** Суточный лимит 35 000 токенов с умным резервированием под запланированные авто-рассылки (средний расход + 20%) и детальной статистикой. |
| 💾 **Сохранение** | **Надежное хранение:** Измененные в боте промпты и настройки сохраняются в локальный JSON-файл и больше не сбрасываются при перезапуске программы. |
| 🧹 **Форматирование** | **Безопасная верстка:** Ответы очищаются от символов Markdown (`#`, `*`, `_`, `~`), а служебные тексты экранируются от ошибок HTML-разметки Telegram. |

<a id="запуск-в-visual-studio"></a>
## 🚀 Запуск в Visual Studio / VS Code

```text

Для запуска проекта на локальном компьютере выполните следующие шаги:

1. Подготовка ключей доступа

  - Получите токен Telegram-бота у @BotFather.
  - Получите API-ключ Google Gemini в Google AI Studio.

2. Настройка переменных окружения

Создайте в корневой папке проекта файл .env и укажите ваши ключи:

TELEGRAM_BOT_TOKEN=1234567890:ААА_ваш_токен_телеграм
GEMINI_API_KEY=AIzaSy_ваш_ключ_gemini

3. Установка и запуск через терминал VS

Откройте проект в Visual Studio или VS Code, нажмите Ctrl + ~ для открытия
терминала и выполните:

# 1. Создание виртуального окружения Python
python -m venv venv

# 2. Активация окружения (Windows)
.\venv\Scripts\activate

# 3. Установка зависимостей
pip install -r requirements.txt

# 4. Запуск бота
python bot.py

💡 Примечание по региональным ограничениям: Поскольку Google Gemini API
ограничено в некоторых регионах, при локальном запуске с территории РФ
убедитесь, что на компьютере включен VPN или настроен прокси.
```

<a id="архетиктура"></a>
## 📁 Архитектура проекта

```text

Файловая структура проекта:

├── bot.py           — Главный модуль. Содержит обработчики команд, клавиатуры, FSM-состояния и безопасный вывод HTML.
├── gemini_client.py — Взаимодействие с Google Gemini API (модель gemini-3.6-flash, Google Search Tool, фолбэки при 429/503).
├── scheduler.py     — Асинхронный планировщик задач (APScheduler) для авто-рассылки отчетов подписчикам.
├── storage.py       — Хранение настроек и подписчиков (data/data.json), управление токенами, резервом и дефолтными промптами.
├── data/            — Папка (создается автоматически) для хранения локальной базы данных data.json и бэкапов.
├── .env             — Конфигурационный файл с ключами доступа (не загружается в Git).
└── requirements.txt — Список библиотек Python.
```
