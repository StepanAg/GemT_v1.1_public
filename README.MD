## ✨ Возможности бота

| Категория | Описание функционала |
| :--- | :--- |
| 👥 **Подписка** | **Автоматическая регистрация:** при отправке команды `/start` пользователь регистрируется в базе рассылки с сохранением метаданных (username, имя, дата подписки). Доступно управление подпиской через кнопки «❌ Отписаться» и «✅ Подписаться». |
| ⏰ **Расписание (4 отчета)** | **Гибкий планировщик:**<br>• *1W Ликвидность* (пятница, 13:30) — еженедельный регуляторный дайджест ЦБ РФ, Минфина и Казначейства.<br>• *1W CNY* (вторник, 14:00) — еженедельный обзор юаневой ликвидности и рынка облигаций.<br>• *Погашения CNY* (1-е число месяца, 15:00) — ежемесячный график выплат и оферт на 18 месяцев.<br>• *1M КУАП* (5-е число месяца, 16:00) — ежемесячная комплексная справка для КУАП (СЗКО).<br>Дни недели, числа месяца (1–28) и время настраиваются индивидуально для каждого отчета. |
| 🚀 **Экспресс-генерация** | **Мгновенный запуск:** раздел «🚀 Отправить сейчас» позволяет в один клик сформировать любой из 4 отчетов в реальном времени. |
| 💬 **ИИ-Консультант** | **Свободный диалог:** ответы на произвольные аналитические и методологические вопросы с актуальным поиском информации через **Google Search Tool**. |
| 🛑 **Контроль задач** | **Прерывание генерации:** команда `/stop` моментально отменяет текущую активную генерацию пользователя через `asyncio.Task.cancel()`, а в режиме ожидания ставит на паузу глобальную рассылку. |
| 🧙‍♂️ **Ролевая модель** | **Экспертиза СЗКО (2 в 1):** ИИ совмещает роли методолога Банка России и руководителя казначейства/ALM, опираясь на 17 приоритетных официальных источников (cbr.ru, minfin.gov.ru, moex.com, rusbonds.ru, garant.ru и др.). |
| 🎨 **Telegram Rich Message** | **Двухстадийный пайплайн:** генерация выполняется моделью `gemini-3.6-flash`, после чего специализированный модуль `TextFormatter` (`gemini-3.5-flash-lite`) структурирует ответ под нативный Telegram Rich Message (Markdown-таблицы, списки, выделения) с каскадным фолбэком до обычного `sendMessage`. |
| 🪙 **Умный контроль лимитов** | **Резервирование токенов:** суточный лимит 35 000 токенов. В дни запланированных рассылок бот автоматически бронирует токены (средний расход за 30 дней + 25%), предотвращая их исчерпание личными запросами. Сброс лимита выполняется строго в 00:00 по МСК. |
| 🛡 **Надежность данных** | **Атомарное хранилище:** сохранение данных через временные файлы (`.tmp`) с созданием резервной копии (`.bak`) и синхронизацией `fsync`. |

## 📋 Аналитические отчеты

### «1W ликвидность» (еженедельно)
Мониторинг регуляторных изменений Банка России, Минфина и Федерального Казначейства за последние 7 дней. Фокус на нормативы Н2–Н4, Н26/Н27, ВЛА, операции казначейства и практические рекомендации для КУАП/Риск-комитета.

### «1W CNY» (еженедельно)
Комплексный обзор юаневого сегмента финансового рынка: динамика ставок межбанковского рынка (RUSFAR CNY), операции валютного свопа ЦБ РФ, события трансграничных расчетов и сводная таблица первичных размещений юаневых облигаций.

### «Погашения CNY» (ежемесячно)
Хронологический график выплат, плановых погашений и всех типов оферт (Put/Call) по корпоративным юаневым облигациям на Мосбирже объемом от 1 млрд CNY на горизонте 18 месяцев вперед. Включает агрегированную сводку и анализ пиковых выплат.

### «1M КУАП» (ежемесячно)
Справка для Комитета по управлению активами и пассивами банка уровня СЗКО: 7 ключевых тезисов (Факт/Оценка/Прогноз), таблица макроиндикаторов (RUONIA, спреды свопов, структурный баланс ликвидности), действия регулятора и календарь дат риска на будущий месяц.

## ⚙️ Переменные окружения (.env)

Создайте файл `.env` в корневом каталоге проекта:

```env
# Обязательные параметры:
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
GEMINI_API_KEY=AIzaSyD-ВашБазовыйКлючGemini

# Опциональные параметры:
# Второй API-ключ для форматирования (для разделения квот и нагрузки)
FORMATTER_GEMINI_API_KEY=AIzaSyD-ВторойКлючФорматтера

# Модель для форматирования Markdown/Rich Message (по умолчанию gemini-3.5-flash-lite)
FORMATTER_GEMINI_MODEL=gemini-3.5-flash-lite

# Директория для хранения базы данных data.json (по умолчанию data или /app/data в Docker)
DATA_DIR=data
```

## 🚀 Быстрый запуск

### Локальный запуск

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/your-username/treasury-gemini-bot.git
cd treasury-gemini-bot

# 2. Создайте и активируйте виртуальное окружение
python -m venv venv
source venv/bin/activate   # Linux/macOS
# venv\Scripts\activate    # Windows

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Настройте файл .env (см. выше)

# 5. Запустите бота
python bot.py
```

> 💡 **Важно при размещении на сервере:** сервер должен иметь сетевой доступ к сервисам Google Gemini API (находиться в поддерживаемом Google регионе).

## 📁 Архитектура проекта

```text
├── bot.py            — Главный модуль. Aiogram-роутинг, иерархические меню, FSM-состояния и guard-фильтры.
├── gemini_client.py  — Взаимодействие с Google GenAI SDK (gemini-3.6-flash, Google Search Tool, отправка Rich Message).
├── formatter.py      — Модуль переформатирования ответов в Telegram Rich Message через вспомогательную модель.
├── scheduler.py      — Фоновый планировщик APScheduler (CronTrigger для еженедельных и ежемесячных задач, сброс лимитов в 00:00 МСК).
├── storage.py        — Атомарное JSON-хранилище (data.json), учет токенов (+25% резерв), дефолтные промпты и подписчики.
├── requirements.txt  — Список внешних зависимостей.
└── README.md         — Документация проекта.
```
